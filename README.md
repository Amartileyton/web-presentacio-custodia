# Web Presentació Custòdia de Detinguts - CGIA Grup 3

Presentació interactiva per al projecte de millora del procés de custòdia de detinguts i reducció de contencions a les Àrees de Custòdia de Detinguts (ACD) de la Policia de la Generalitat - Mossos d'Esquadra (PG-ME).

## Contingut del Projecte

- **`index.html`**: Estructura principal de la presentació web interactiva.
- **`Presentacio_CGIA_Custodia_Contencions_Grup3.html`**: Versió compilada/autònoma (bundle) llesta per a distribuir i visualitzar sense dependències locals.
- **`css/styles.css`**: Full d'estils de la presentació.
- **`js/app.js`**: Lògica interactiva, animacions dels diagrames de flux ASME, comptadors i transicions entre fases.
- **`diagrama_asme_detencio.html`**: Diagrama de flux ASME interactiu del procés de detenció.
- **`bundle.py`**: Script en Python per compilar tots els recursos (CSS, JS, imatges en base64) en un únic fitxer HTML autònom.

## Fases del Procés de Millora

1. **Fase 1**: Identificar el procés a millorar (Diagrama de flux ASME inicial)
2. **Fase 2**: Analitzar el procés a millorar (Xoc de dades i indicadors clau)
3. **Fase 3**: Proposar millores en el procés
4. **Fase 4**: Implementar millores en el procés
5. **Fase 5**: Fer el seguiment de les millores implantades
